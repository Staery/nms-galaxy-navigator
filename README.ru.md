Панель внутри игры для галактической карты **No Man's Sky**. Все звёздные системы в пределах прыжка собраны в одну
сортируемую таблицу. Её можно отфильтровать по экономике, богатству, конфликту, расе, цвету звезды, аномалиям,
планетам и другим признакам. **Автомаршрут** находит путь с наименьшим числом прыжков (при равенстве — с меньшим
числом световых лет) и при каждом открытии карты сам выбирает следующую систему.

Родная карта игры показывает по одной системе за раз. Мод берёт все ~15 000 систем, которые карта уже загрузила,
определяет их признаки функцией самой игры и даёт выбрать систему из списка. Прыжок — обычный прыжок игры:
мод только выбирает цель, как если бы вы щёлкнули по ней сами. Поэтому топливо, анимация и сетевая игра работают
как обычно. В сейв и в файлы игры ничего не пишется.

На экране инвентаря мультитула, корабля или экзокостюма мод добавляет карточку со **скрытыми статами**: базовые
статы с диапазоном для класса предмета, максимумом класса S и местом значения в диапазоне, а также все
модули-улучшения с точными выпавшими значениями (мод читает их из игры, когда модуль генерируется) и тем, насколько
каждое близко к лучшему возможному. Те же базовые статы из сейва показывает и небольшая консольная программа.

> **Версия игры.** Сделано и проверено на **No Man's Sky 7.10** (Steam, сборка 26271400, октябрь 2026),
> NMS.py 181442.1 и pyMHF 0.2.5, одиночная игра. Смещения в памяти карты найдены реверсом и могут сдвинуться
> после обновления игры — см. [Состояние проекта](#состояние-проекта).

## Как это работает

```text
кэш галактической карты (cGcGalaxyMap.Data): позиции[n] (3 × f32), адреса[n] (u64), ~27 регионов вокруг камеры
1 единица карты = 4 св. года;   регион = 100 единиц
абсолютная позиция (св. л.) = (позиция + 100 × центр кэша) × 4    — не меняется, когда кэш перецентрируется
признаки = ClassifyStarSystem(адрес)                              — тот же вызов, что у попапа карты
```

```text
маршрут: BFS по слоям прыжков внутри кэша, ребро = расстояние ≤ дальности прыжка и звезда доступна приводу
         внутри слоя — наименьшая сумма св. лет (DP)
         цель за краем кэша → путь до края кэша, остаток оценивается как ⌈d / дальность⌉
         после каждого прыжка маршрут пересчитывается от новой системы
```

Выбор системы вызывает функцию выбора самой карты с запросом, собранным так же, как карта собирает его для системы
в прицеле. Поэтому игра показывает свой обычный попап и подсказку прыжка.

## Требования

- Windows 10/11, No Man's Sky в Steam (7.10).
- Python 3.13 x64 (для pyMHF / NMS.py).
- Панель на карте управляется с клавиатуры: свободного курсора на карте нет.

## Установка

1. **Получить код**

   ```bash
   git clone https://github.com/Staery/nms-galaxy-navigator.git
   ```

2a. **В один клик (Windows)** — запустите `Install.bat`. Он создаст `tools\venv` с pyMHF и NMS.py и покажет
   строку для параметров запуска Steam.

2b. **Вручную**

   ```bash
   py -3.13 -m venv tools\venv
   tools\venv\Scripts\python -m pip install -r requirements.txt
   ```

3. **Запуск игры с модом.** Steam → No Man's Sky → Свойства → Параметры запуска:

   ```text
   "C:\путь\к\nms-galaxy-navigator\launch.cmd" %command%
   ```

   `launch.cmd` запускает игру, ждёт её окно и подключает мод. Не закрывайте окно консоли во время игры.
   Без параметра запуска игра запускается как обычно. Логи пишутся в `logs/`.

**Настройки.** Папка игры определяется по запущенному `NMS.exe`. Для консольных инструментов задайте
`NMS_GAME_DIR`, если Steam не находится через реестр.

## Использование

Откройте галактическую карту. Клавиши:

| Клавиша | Действие |
|---|---|
| F8 | показать / скрыть панель |
| F7 | список ↔ фильтры |
| ↑ ↓, PgUp PgDn | двигать выделение (в фильтрах — выбрать фильтр) |
| ← → | сортировка (в фильтрах — сменить значение) |
| F9 | выбрать выделенную систему на карте, дальше прыжок как обычно |
| F10 / F11 | маршрут к выделенной строке / к системе в прицеле |
| F6 | сбросить фильтры (в списке — сбросить маршрут) |

На экране инвентаря **F5** сортирует экзокостюм и основной корабль вместе. Вещества и товары обоих сводятся
в полные стопки, упорядочиваются (вещества, затем товары, по ID) и раскладываются с первой свободной ячейки
корабля, оставляя в нём несколько свободных ячеек (`sort_keep_free`); остаток — в экзокостюм, а отложенные
ячейки корабля занимаются, только если иначе не помещается. Технологии, сломанные ячейки и ячейки только для техники не трогаются.
Если что-то не сходится, всё возвращается как было.

**Настройки** — `settings.json` рядом с `launch.cmd`, создаётся при первом запуске; правки применяются за пару секунд:

| Ключ | По умолчанию | |
|---|---|---|
| `galaxy_panel` | `true` | панель систем на галактической карте |
| `auto_route` | `true` | следующая система маршрута выбирается на карте сама |
| `inventory_stats` | `true` | карточка скрытых статов в инвентаре |
| `inventory_sort` | `true` | сортировка по F5 в инвентаре |
| `sort_fill_first` | `"ship"` | куда класть сначала: `ship` (экзокостюм остаётся как можно свободнее) или `exosuit` |
| `sort_keep_free` | `5` | сколько ячеек оставить свободными там, куда кладём сначала, если всё помещается и так (0–120) |

Скрытые статы из самого свежего сейва:

```bash
python nms_stats.py            # или: python nms_stats.py путь\к\save3.hg
```

## Структура проекта

```text
mod/
  galaxy_list.py      мод pyMHF: хуки, рисование nanovg, клавиши, разбор кэша карты, поток маршрута
  galaxy/model.py     подписи, фильтры, сортировка, состояние панели (работает без игры)
  galaxy/route.py     автомаршрут (numpy)
  galaxy/i18n.py      определение языка и поиск строк; i18n_ui.json — свои строки
  invstats.py         статы инвентаря: чтение хранилища и модулей из памяти, строки карточки (тесты без игры)
  invsort.py          общая сортировка экзокостюма и корабля (тесты на модели Add/Remove игры)
  modsettings.py      settings.json: умолчания, проверка, перечитывание
  proto_map.py        прототип этапа 1 с пробами памяти (заметки реверса)
data/
  tables.json         диапазоны статов (build_tables.py из MXML-таблиц игры)
  i18n_game.json      игровые термины на 17 языках (build_i18n.py)
  mapping.json        ключи сейва (MBINCompiler)
nmssave.py            читалка сейва        nms_stats.py   консоль скрытых статов
statinfo.py           логика статов, общая для консоли и мода
nmspaths.py           поиск папки игры и Steam
tools/sigscan.py      проверяет, что сигнатуры хуков NMS.py совпадают с NMS.exe
launch.cmd, Install.bat
tests/
```

## Тесты

```bash
python -m pytest -q
```

Тесты проверяют читалку сейва, фильтры и подписи, маршрут, диапазоны и проценты статов, разбор памяти инвентаря
(на синтетической памяти) и переводы (каждый ключ на каждом языке, совпадение
подстановок). Сам мод проверяется в игре.

## Состояние проекта

**Сделано**
- Панель систем в радиусе с фильтрами и сортировкой, штатный прыжок, автомаршрут с автовыбором следующей системы.
- Гипердвигатель и сканеры читаются из сейва; 17 языков с автоматическим переключением.
- Карточка скрытых статов на экране инвентаря (мультитул, корабль, экзокостюм) и консоль скрытых базовых статов.
- Общая сортировка экзокостюма и корабля (F5) и настройки включения каждой функции.

**Ещё не сделано**
- Имена систем в списке.
- Проверка в сетевой игре (прыжок штатный, но с друзьями ещё не проверялся).
- Полный прогон сортировки F5 в игре (пока проверена на модели штатных Add/Remove; при любом расхождении — откат).
- Полный прогон сортировки F5 в игре (пока проверена на модели штатных Add/Remove; при любом расхождении — откат).

**Известные пробелы**
- В шрифте карты нет китайских, японских и корейских знаков — для этих языков панель показывается на английском.
- Переводы, кроме английского и русского, машинные и могут отличаться от формулировок игры.
- То, что старший гипердвигатель открывает и младшие цвета звёзд, — предположение.
- После обновления игры смещения в `mod/galaxy_list.py` может понадобиться найти заново; сначала запустите
  `tools/sigscan.py`.
